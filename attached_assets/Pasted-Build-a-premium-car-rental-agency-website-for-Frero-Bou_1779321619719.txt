✨ FRAMER MOTION USAGE
━━━━━━━━━━━━━━━━━━━━━━━━━
Use Framer Motion for ALL animations:
- Page load: hero text stagger (staggerChildren: 0.15)
- Scroll-triggered: useInView + variants (hidden → visible)
- Cards: staggered children with y: 40 → 0, opacity: 0 → 1
- Navbar: height + blur on scroll with useScroll + useTransform
- Filter active state: layoutId="activeFilter" shared layout
- Modal: scale(0.9) → scale(1) + opacity with AnimatePresence
- WhatsApp button: infinite pulse scale animation
- Stats counter: animate numbers 0 → final value on inView
- Hover states: whileHover={{ scale: 1.02, y: -4 }} on cards
- Tap feedback: whileTap={{ scale: 0.97 }} on buttons
